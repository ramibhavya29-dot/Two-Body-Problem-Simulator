## Submitted Materials

This submission contains a browser-based interactive two-body gravitational simulator as supplementary material for ME206 Assignment 4.

The project includes:

- `index.html` — application entry point and interface structure.
- `style.css` — responsive dark-space interface and presentation styling.
- `script.js` — Newtonian equations, velocity Verlet integration, presets, telemetry, charts, collision handling, and canvas rendering.
- `README.md` — reproducibility, physics, controls, installation, and troubleshooting documentation.
- `.gitignore` — repository exclusions for temporary and editor-specific files.

The simulation supports adjustable masses and initial conditions, fixed-physics-step animation, orbital presets, live conservation indicators, Chart.js graphs, zoom and pan controls, presentation mode, and high-speed simulation with an achieved-speed indicator.
